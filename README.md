The Doctor Appointment Booking System (DABS) is a web-based healthcare management application developed using Django in Python. The system is designed to automate and simplify the appointment scheduling process in hospitals and clinics. It allows patients to securely register, log in, search doctors by specialization, view doctor profiles, and book appointments based on available time slots.

The system includes a centralized scheduling mechanism where doctor availability is managed through the admin panel to prevent double-booking and maintain organized appointment handling. A priority-based scheduling feature is also implemented to prioritize critical appointments based on urgency and waiting time. The project aims to improve healthcare service efficiency, reduce manual workload, and enhance patient experience through an organized and user-friendly digital platform.
